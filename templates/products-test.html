ℹ️ Thông Tin

  • Mở Network tab để xem request GET /static/data/products.json
  • Tất cả method là async - sử dụng await hoặc .then()
  • Global instance: productsAPI - có sẵn trong browser
  • File data: static/data/products.json
  • File API: static/js/products-api.js

💻 Ví Dụ Code

// Ở trong console hoặc file JS:

// 1. Lấy tất cả sản phẩm
const products = await productsAPI.getAllProducts();

// 2. Lấy sản phẩm theo ID
const product = await productsAPI.getProductById('PROD-001');

// 3. Lấy Halloween products
const halloween = await productsAPI.getHalloweenProducts();

// 4. Tìm kiếm
const results = await productsAPI.searchProducts('Bunnie');

// 5. Lấy phụ kiện
const heads = await productsAPI.getAccessoriesByType('head');

// 6. Sắp xếp theo giá
const sorted = await productsAPI.getProductsSortedByPrice('asc');
