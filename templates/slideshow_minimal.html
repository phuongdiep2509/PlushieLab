📝 How to Customize

1️⃣ Change Image URLs

Replace the src URLs in each <img> tag with your own image paths. 

<img src="your-image-url-here.jpg" alt="Slide 1" />

2️⃣ Add More Slides

Copy a <div class="slide"> block and paste it. Add a corresponding <li class="dot"> in the indicators section.

3️⃣ Adjust Timing

In JavaScript, change the interval: 

new ImageSlideshow('my-slideshow', { 
  autoplayInterval: 3000  // 3 seconds instead of 2
});

4️⃣ Hide Auto-play Badge

Remove or comment out this line: 

<!-- <div class="autoplay-indicator playing"><span>Auto</span></div> -->

5️⃣ Change Container Size

Edit the outer <div> styling or CSS in static/css/slideshow.css: 

.slideshow-container {
  max-width: 600px;  /* Change this */
  margin: 0 auto;
}

🎮 How Users Control It

Action How
Next slide Click › button or press → arrow key
Previous slide Click ‹ button or press ← arrow key
Jump to slide Click any dot indicator
Pause auto-play Click "Auto" badge or hover mouse
