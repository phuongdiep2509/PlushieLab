CUSTOMIZATION EXAMPLES
================================================================================

CHANGE SPEED (3 seconds instead of 2):
   new ImageSlideshow('id', { autoplayInterval: 3000 })

DISABLE AUTO-PLAY:
   new ImageSlideshow('id', { autoplay: false })

CUSTOM COLORS:
   Edit static/css/slideshow.css
   • .slide-nav-btn { background: your-color; }
   • .dot { background: your-color; }

HIDE AUTO-PLAY BADGE:
   Comment out <div class="autoplay-indicator"> in component

================================================================================
TROUBLESHOOTING
================================================================================

Q: Slideshow not showing?
A: Check that data-slideshow attribute exists on container
   Check image paths are absolute (/static/..., not relative)

Q: Auto-play not working?
A: Check slideshow.js is loaded
   Check autoplay option is not set to false
   Open console (F12) for errors

Q: Styling looks wrong?
A: Ensure slideshow.css is linked in base.html
   Clear browser cache (Ctrl+Shift+R)
   Check CSS specificity

Q: Buttons not working?
A: Open console (F12) and check for errors
   Verify JavaScript is enabled
   Check slideshow.js file exists
